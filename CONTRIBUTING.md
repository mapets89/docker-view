# Contributing

DockerView is not accepting external pull requests at this time. The repository is public so it can be inspected, used, and forked, but project direction and changes are currently maintainer-controlled. Please do not open feature PRs or contributor-onboarding issues.

Security reports are an exception: follow [SECURITY.md](SECURITY.md) and never publish sensitive vulnerability details in a public issue.

For local changes, run `make test lint typecheck security` and ensure `docker compose config` and both image builds succeed. Contributions may be opened in the future; this file will be updated first.
