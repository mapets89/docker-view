# Roadmap

Future work, not present in V1: Projects; Docker Compose grouping; multi-host and host agents; OIDC/Keycloak; mTLS Gateway authentication; external/immutable audit sinks (CloudWatch, Loki, syslog); read-only mode; production hardening; multi-environment comparison; advanced lifecycle operations; and backup tooling.

Image, volume, network, deployment, Kubernetes, and arbitrary Docker API management are intentionally outside the current product.
